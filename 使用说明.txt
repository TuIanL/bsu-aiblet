安行护腰 UI 源码使用说明（含网页端社区管理平台）
================================================

一、查看网页（前台展示）
先完整解压压缩包，再用 Chrome 或 Edge 打开 index.html。
请保留所有文件在同一个文件夹，图片、样式及交互脚本才能正常加载。


二、启动后台与设备接入（推荐）
后台管理页与事件流程回放页需要本地服务运行，不能直接双击 HTML 打开。

方式 A：双击启动
  双击「启动平台.command」，会自动启动服务并打开浏览器。
  首次运行会自动初始化演示数据库。
  用完双击「关闭平台.command」即可停止服务与模拟器，释放 8848 端口。

方式 B：命令行
  启动：cd 到本文件夹，执行：
      python3 server/app.py
  看到「已启动」后打开：
      前台展示      http://127.0.0.1:8848/index.html
      后台管理      http://127.0.0.1:8848/admin.html      演示口令 8888
      事件流程回放  http://127.0.0.1:8848/event-flow.html

  停止：
      按 Ctrl+C 停止服务
      或在另一终端执行：
      pkill -f "server/app\.py"; pkill -f "server/simulator\.py"

  Windows 可用 py server\app.py。


三、让设备「活」起来（设备接入演示）
另开一个终端，在同一文件夹执行：
      python3 server/simulator.py

它扮演真实硬件网关，周期性向平台上报：
  · 遥测（电量、储气压力、佩戴时长、佩戴状态）
  · 事件（跌倒 / 险跌 / 误报 / 设备告警）
后台页面通过实时数据流自动刷新，无需手动刷新。

单次触发（演示用）：
      python3 server/simulator.py --fall          立即触发一次跌倒
      python3 server/simulator.py --once          只发一帧遥测
      python3 server/simulator.py --fall --kind 险跌
      python3 server/simulator.py --device AXB-2026-0005

接入真实硬件时，把 simulator.py 换成网关的 HTTP 客户端即可，
调用同样的接口，平台侧不需要任何改动：
      POST /api/ingest/telemetry   遥测上报
      POST /api/ingest/event       事件上报


四、两个新页面是什么

admin.html —— 网页端社区管理平台（对应商业计划书表 3-3）
  运营总览 / 事件与响应 / 设备台账 / 老人档案与评估 /
  佩戴率看板 / 社区风险分布 / 季度报告与改造建议 / 全流程操作日志
  事件详情里可直接执行：确认接单 → 标记到场 → 填写处置结果 → 填写复盘。

event-flow.html —— 一次完整设备事件流程回放
  把一次事件拆成五段，每段都是对应界面的高保真还原：
    01 设备事件  端侧识别失衡、气囊展开、传感器读数、动作顺序
    02 平台记录  事件入库、风险识别特征、关联老人档案、留痕
    03 消息      社区网格 + 家属双通道，含手机端推送界面还原
    04 人工响应  工单派发、接单、到场、现场处置与就医情况
    05 复盘      根因分析、回流热力图、适老化改造建议
  顶部下拉框可切换任意事件，右侧为全流程时间线与关键指标。


五、修改源码
  index.html          前台页面结构与文字
  styles.css          前台配色、排版、响应式
  app.js              前台导航、详情弹窗、移动菜单、咨询表单
  admin.html          后台管理页结构
  event-flow.html     事件流程回放页结构
  assets/platform.css 平台端共享样式
  assets/platform.js  API 客户端、鉴权、格式化、实时数据流
  assets/admin.js     后台业务逻辑
  assets/flow.js      流程回放渲染逻辑
  server/db.py        数据表结构与演示数据
  server/app.py       HTTP 服务、REST 接口、实时推送、静态托管
  server/simulator.py 设备网关模拟器
  server/data/        SQLite 数据库（首次启动自动生成）
  brand-logo.png / belt-front.png / belt-flat.png  产品图片


六、数据说明
  · 演示数据库为颐清园养老社区服务驿站：12 名老人、12 台设备、30 天事件记录。
  · 其中包含一条走完全流程的跌倒事件（气囊展开 → 双通道通知 → 网格员响应 → 复盘 → 改造建议），
    默认在流程回放页首屏展示。
  · 重置数据：删除 server/data/platform.db 后重启服务即可重新生成。
  · 页面内所有性能数值、风险判定与处置结论均为演示数据。项目当前处于概念验证阶段
    （TRL 3–4），不代表整机实测结果，不构成医学诊断。


七、部署
前台官网仍为纯静态网页，可直接上传至静态服务器。
后台管理平台与流程回放页需要能运行 Python 3 的服务端，
部署时把整个文件夹上传后执行 python3 server/app.py --port 8848 即可。


八、功能范围
  · 前台官网：导航、弹窗、咨询表单（表单为前端演示，未接邮件服务）。
  · 后台管理平台：可运行，数据来自本地 SQLite 与设备网关上报。
  · 子女端 App：仍为网页展示，未包含原生手机应用。
  · 设备接入：模拟器演示，协议与真实网关一致，未接真实硬件。
